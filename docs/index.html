Security Whitepaper Summary

Engineered to the security standard of protecting banking and critical infrastructure credentials.

1. Two-Key Envelope Hierarchy

A random 256-bit Vault Key (VK) is generated locally. A Key Wrapping Key (KWK) is derived from your master password using Argon2id / PBKDF2-SHA256 with a unique salt. The KWK wraps the VK using AES-256-GCM. Changing your master password re-encrypts only the small envelope, eliminating risk of payload corruption.

2. In-Memory Hygiene & Zeroization

Decrypted secrets and unwrapped keys are strictly scoped. When the vault locks on idle timeout or user command, active memory buffers are explicitly wiped with zeros, defeating memory scraping exploits.

3. Phishing-Resistant Autofill Domain Matching

The Chrome extension checks effective top-level domains (eTLD+1) before injecting credentials, strictly preventing lookalike domains and subdomain impersonation attacks.

Summary of Our Zero-Knowledge Privacy Commitments

Kloak operates on the fundamental principle of absolute local-first security and zero-knowledge data privacy. We operate no cloud user accounts, no remote password databases, no analytics, and neither the desktop app nor the browser extension ever shares any data back to our servers or developers. All data found, inspected, or managed is kept 100% natively within your local operating system.

🔒 100% On-Device Vault Encrypted locally with AES-256-GCM on your computer. Zero cloud databases.
🛡️ Zero Data Sent Back Neither the app nor extension sends data back. All data stays strictly on your machine.
🚫 No Remote Code 100% statically bundled at build time. No remote scripts or CDNs loaded at runtime.
🌐 Zero Ads & Profiling No telemetry, no tracking cookies, and zero behavioral advertising.

1 Scope & Single Purpose Specification

This Privacy Policy applies to the Kloak Password Manager software ecosystem:

  • Kloak Password Manager Chrome Extension (Chrome Web Store ID: hajgkgmajepndkhjhcgjenjnfojlphod)
  • Kloak Password Manager Native macOS Application (Installer Package: Kloak-macOS.dmg)
  • Kloak Raycast Extension
  • Official open-source repository at github.com/naetikarvind/kloak
Single Purpose Declaration: The single purpose of the Kloak Chrome Extension is to securely autofill login credentials, passkeys, and two-factor authentication (TOTP) codes from the user's local, encrypted vault directly into website login forms upon user request. All features exist solely to facilitate and protect this singular credential filling flow.

2 User Data Collection

In accordance with Chrome Web Store User Data policies, this section explicitly discloses every category of data accessed or handled:

2.1 Authentication Information (Credentials & Secrets)

Usernames, passwords, passkeys, TOTP 2FA secrets, notes, and optional payment card details voluntarily saved by the user. Handled 100% on-device and never uploaded to any cloud server.

2.2 Website Content & Input Fields (Processed 100% Natively)

HTML input elements (<input type="password">, <input type="text">) detected locally by content.js to display the autofill badge. Form structures remain strictly in local RAM and are never phoned home.

2.3 Active Tab Domain (URLs)

The active domain (e.g. github.com) is read in ephemeral memory via the tabs API to search the local vault for matching logins and verify against phishing. Browsing history is never saved or transmitted.

2.4 Categories of Data NEVER Collected

Kloak affirms that it does NOT collect personal communications, geolocation, health data, hardware identifiers, browsing history logs, or telemetry/analytics.

3 User Data Handling and Use

Every piece of data accessed by Kloak is handled solely to execute core credential autofill, 2FA code generation, phishing protection, and password generation.

Mandatory Chrome Web Store Policy Affirmations:
  • We do NOT use or transfer user data for purposes unrelated to the extension's core single purpose.
  • We do NOT use or transfer user data to serve personalized, targeted, or behavioral advertisements.
  • We do NOT use or transfer user data to determine creditworthiness or for lending purposes.
  • We do NOT use user data for surveillance, user tracking, or data profiling.

4 User Data Storage, Retention, and Security

All credentials are stored 100% locally on your computer at ~/.kloak/vault.kloak using authenticated AES-256-GCM encryption with Argon2id key derivation. Communication between the Chrome extension and desktop application occurs strictly over local OS native messaging pipes (app.kloak.native) and loopback socket (127.0.0.1:53152), never traversing external networks.

5 User Data Sharing & Third Parties

Absolute Ban on Selling & Sharing: Neither the app nor the extension shares any data back to our developers or remote servers. All found data is kept strictly and natively within your local operating system at all times. We do NOT sell, lease, or monetize user data under any circumstances.
